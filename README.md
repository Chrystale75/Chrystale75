## Mineral Collection App

A simple command-line app to manage your mineral collection.

### Setup

1. Initialize the database:

```bash
python3 -m minerals_app.cli init
```

2. Add a mineral:

```bash
python3 -m minerals_app.cli add "Quartz" --color clear --location Brazil --notes "typical"
```

3. List minerals:

```bash
python3 -m minerals_app.cli list
```

See `python3 -m minerals_app.cli --help` for more commands.
